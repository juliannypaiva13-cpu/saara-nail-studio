# Protótipo aprovado (Etapa 1): referência, não é publicado

Cópia fiel do protótipo interativo aprovado. Serve de referência para as telas reais da Fase 3:
design, páginas, preços, durações e funcionalidades. **Não é publicado** pelo Cloudflare (o `scripts/build.mjs` nunca o copia para `dist/`).
Os dados de clientes que aparecem nele são de exemplo. Os únicos dados reais são os públicos do estúdio
(WhatsApp, endereço, chave Pix por e-mail, logo e foto), aprovados para o site.
